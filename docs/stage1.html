The Baseline Model

Before you can study when a model fails, you need a model that works. This stage trains a standard image classifier — ResNet-18 on CIFAR-10 — three independent times, so every later finding rests on more than one lucky run.

1 Why a baseline first?

The research question is about explanations of a trained model under stress. That only makes sense if the model is genuinely good on clean data first — otherwise its heatmaps explain nothing worth trusting.

So Stage 1 produces a clean, well-trained classifier and nails down its accuracy. Everything downstream — corruptions, heatmaps, drift — runs on these exact checkpoints.

2 The model — ResNet-18 (CIFAR variant)

A standard 18-layer residual network, adapted for small 32×32 images.

Two residual blocks per stage. layer4 (highlighted) is where Grad-CAM reads from; its 4×4 map is why Grad-CAM is coarse here.

Key design choice — normalisation lives inside the model. Images go in as raw [0,1] pixels and the model normalises them internally. This keeps the Integrated-Gradients black baseline and the CIFAR-10-C corruptions all in the same raw-pixel space, so nothing has to be un-normalised later.

Two differences from the ImageNet ResNet-18: a 3×3 first conv (not 7×7) and no initial max-pool, so a 32×32 image isn't shrunk away before the network sees it.

3 The data

The 50,000 training images are split 45,000 / 5,000 (train / validation) with a fixed seed. The 10,000 test images are held back entirely. Augmentation on the training set: random 32×32 crop with 4-pixel padding, and a random horizontal flip. Validation and test get no augmentation.

No peeking at the test set. The model is chosen on validation accuracy alone; the 10,000-image test set is evaluated exactly once, at the very end, to report the clean accuracy. This keeps the headline number honest.

5 Why three seeds?

A seed fixes all the randomness in a run — the initial weights, the shuffling, the augmentation. Train three times with different seeds and you get three slightly different models.

A single run could be lucky or unlucky. Training three independent copies lets the project later say "the effect holds across 3 models, and here is the spread" instead of resting a claim on one network. The data split stays fixed across all three — only the training randomness changes — so they're a fair comparison.

7 A note on compute

The plan was to train locally on an RTX 3050 (6 GB). In practice, the CIFAR-10 download from the official server kept stalling and corrupting on a slow connection, and local epochs ran at ~4 min each.

The fix was to train on a free Colab T4, where the data downloads in seconds and a full 40-epoch run finishes in ~15–20 minutes. Seed 0 was redone there too, so all three checkpoints come from the same environment — one less thing to vary between them.
