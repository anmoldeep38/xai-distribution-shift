Distribution Shift

1 What is distribution shift?

A model is trained on clean images and tested on clean images. But once deployed, the images it meets are often degraded — a dirty camera lens, low light, fog, JPEG artefacts. The input distribution has shifted away from what the model learned.

The danger isn't just that accuracy drops — it's that the model can stay confident while being wrong. This project is ultimately about catching those silent failures, and to study them we first need a controlled, repeatable way to shift the images.

2 CIFAR-10-C — a corruption benchmark

CIFAR-10-C is the standard benchmark for this (Hendrycks & Dietterich, 2019). It takes the 10,000 clean CIFAR-10 test images and applies 15 algorithmic corruptions, each at 5 increasing severities.

Each corruption file holds all 50,000 images (the 10,000 test images × 5 severities), stored as a NumPy array. The label of a corrupted image is the same as its clean original.

3 The 15 corruptions, in 4 families

The corruptions group into four families. This grouping is what the study's leave-one-family-out test later holds out, to check whether findings generalise to an unseen kind of corruption.

4 How the benchmark was verified

"Verified" means more than "the download finished". Before trusting any later result, four checks confirmed the data is sound — from cheapest to most important.

  • 1All files present — every one of the 15 corruption files plus labels.npy. ✓
  • 2Right shape & type — each corruption is a (50000, 32, 32, 3) array of 0–255 bytes. ✓
  • 3Labels aligned — CIFAR-10-C's labels match the clean CIFAR-10 test order, at every severity. This is the critical one. ✓
  • 4Severity really increases — the average pixel distance from the clean image grows with severity (8.0 → 19.5). ✓
  • 5The model degrades smoothly — accuracy falls monotonically as severity rises (below). ✓
Why check #3 matters most: a corrupted cat must still be labelled "cat". If the labels were out of order, every accuracy number afterwards would be measured against the wrong answers — silently meaningless. Confirming alignment is the one check you cannot skip.

5 Results — the accuracy collapse

Running seed 0 across the severities shows exactly the degradation the project is built to study. And different corruptions bite very differently — noise is brutal, fog is gentle.

From 94% down to 26% under heavy noise — the model is now wrong three times out of four. That gap between "confident on clean data" and "mostly wrong under shift" is the exact territory the heatmap-drift question lives in.
